## 📌 Sobre o projeto

Este repositório reúne estudos e propostas de conteúdo desenvolvidos durante o laboratório **Criando Protótipo Simples**, da Digital Innovation One.

A atividade explora a criação um protótipo de alta ou média fidelidade para o projeto escolhido, aplicando os conceitos de design e usabilidade aprendidos no curso. O objetivo é construir um protótipo navegável no Figma, integrando elementos como List View ou Grid View, e praticar a criação de interfaces funcionais e intuitivas..

## 📌Objetivos de Aprendizagem 
Ao concluir este desafio, você será capaz de: 

Criar um protótipo de alta ou média fidelidade com base em um conceito de produto à sua escolha;
Utilizar o Figma para criar um protótipo navegável e funcional;
Aplicar os conceitos de usabilidade, como a organização de conteúdo e a navegação intuitiva;
Documentar seus objetivos e decisões de forma clara e organizada, utilizando o GitHub como plataforma para exposição do seu trabalho;

Segue meu PRD:

```txt
🖼️ Criação das páginas
Frame (A) → Crie a tela principal (Desktop 1440px ou Mobile 375px).

Logo e Menu:

Insira o logo da Chocolatudo.

Use Text (T) para criar os itens do menu (Home, Produtos, Contato).

Banner:

Crie um Rectangle (R) e insira uma imagem dos brigadeiros.

Cards de produtos:

Crie retângulos com imagens e textos.

Agrupe em Auto Layout (Shift + A) para formar um Grid View.

🗂️ Organização visual
Grid View:

Selecione os cards → Shift + A → configure espaçamento e alinhamento.

List View:

Crie uma lista vertical com imagens + textos (ingredientes, preço).

Botões:

Retângulo arredondado → cor marrom (#5C3A2E) ou rosa (#FADADD).

Texto centralizado em branco ou marrom.

🔗 Protótipo navegável
Na aba Prototype (lado direito do Figma):

Selecione um card de brigadeiro → arraste o nó azul para a Página de produtos.

Configure: On Click → Navigate To → Produtos.

Selecione o botão “Comprar” → arraste para o Frame do carrinho.

Configure: On Click → Navigate To → Carrinho.

No menu superior, cada item deve ter interação:

On Click → Navigate To → Página correspondente.

🎨 Estilo
Cores: Rosa claro (#FADADD), Marrom (#5C3A2E), Branco (#FFFFFF).

Tipografia:

Títulos → fonte cursiva (ex: Pacifico).

Textos → fonte Sans Serif (ex: Open Sans).

👉 Resumindo os comandos principais no Figma:

A → criar Frame (página).

T → inserir texto (menu, títulos).

R → criar retângulo (banner, cards, botões).

Shift + A → aplicar Auto Layout (Grid ou List View).

Aba Prototype → criar links de navegação (On Click → Navigate To).

```

Foi usadoo Copilot Web para revisar e melhorar o seu prompt antes de ir ao Figma, lapidando o texto até que ele fique claro, direto e reflita exatamente a intenção.

> [!TIP]
> O PRD/Prompt pode ser pensado como “o briefing que a IA precisa para entender sua vibe”. Portanto, quanto mais claro e intencional for o texto, mais próximas do ideal serão as respostas da IA.

Durante essa etapa, foi orientado a IA para três entregas principais:
1. Criar um wireframe de média ou alta fidelidade para o seu projeto. Você pode escolher qualquer tema que desejar, não precisa seguir o exemplo do curso. A ideia é que você aplique seus conhecimentos de design de interfaces, criando uma estrutura que seja funcional e esteticamente agradável.

2. Incluir elementos de visualização, como List View ou Grid View, dentro do seu projeto. Esses componentes são essenciais para a organização da informação e navegação na interface.

3. Criar um protótipo navegável no Figma, permitindo que outras pessoas interajam com o design de forma dinâmica e fluída.

O que o site faz?
O site da Chocolatudo Brigadeiro Gourmet tem como objetivo apresentar e vender brigadeiros artesanais e gourmet de forma clara e atraente.

📌 Resumo do que o site faz
Apresenta a marca: mostra o logo, identidade visual e a proposta de valor (brigadeiros artesanais e gourmet).

Exibe os produtos: organiza os brigadeiros em Grid View ou List View, destacando sabores, coberturas e embalagens.

Facilita a compra: cada card de produto tem imagem, descrição, preço e botão “Comprar” ou “Adicionar ao carrinho”.

Navegação simples: menu com links para Home, Produtos e Contato.

Interatividade: protótipo navegável no Figma permite simular a experiência do usuário clicando em cards, botões e menu.

Identidade visual consistente: cores (rosa, marrom, branco) e tipografia cursiva para títulos, transmitindo elegância e doçura.

👉 Em resumo, o site funciona como uma vitrine digital para os brigadeiros gourmet, permitindo que o usuário explore os sabores, veja detalhes e realize a compra de forma prática e agradável.
